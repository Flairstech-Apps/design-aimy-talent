Moving an interview

Only the person whose time it is commits it

A client’s interviewer names the time

AiMY asks the candidate for days and drafts your note to the client.

Moving an interview touches someone else’s calendar, so the rule is: only the person whose time it is decides. If the interviewer is the client’s, like Jana at Northwind, AiMY never offers Jana’s times. It asks the candidate which days suit them and drafts a note for you to send to the client.
