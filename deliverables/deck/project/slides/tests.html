Before we build further, five small tests, each deciding something. Code the client feedback on the last 50 profiles we sent, to know the real decline reasons. Shadow five recruiters for a day, to see how much of their day starts from exceptions. Run an assessment before the call on one support role for two weeks. A think-aloud with five hiring managers, starting with the one who holds twenty requests. And ask two account managers how clients send feedback today, which decides whether the client desk is in AiMY or by email.
